StepDetail

Invariants to remember

  • No database. The source of truth for text is vector metadata.
  • One index, many namespaces. User isolation = namespace = SHA-256(userId), applied on both write and query.
  • Asymmetric embedding. documents for storage, queries for search — never interchangeable.
  • Dates twice. ISO string for display, integer epoch day for $gte filtering.
  • Auth: bearer token via Clerk; only userId from authInfo.extra reaches the store; email allowlist at the HTTP layer.
