# Mission: Clerk test MCP server

## Why
Run and understand this local MCP server so it can become a safe developer tool for Clerk authentication tests. The tool must reduce manual dashboard work when testing users, sessions, and authorization.

## Success looks like
- Start the local HTTP MCP server and connect an MCP client to it.
- Test one Clerk authorization workflow without the Clerk dashboard.

## Constraints
- Use a Clerk test instance only during early development.
- Keep the first workflow small and safe.

## Out of scope
- Clerk production writes.
- Push notification testing until the Clerk workflow works.
