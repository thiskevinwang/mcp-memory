# MCP HTTP Server Resources

## Knowledge

- [Cloudflare Vectorize and Workers AI](https://developers.cloudflare.com/vectorize/get-started/embeddings/)
  Official guide for the embedding model, Vectorize index, bindings, writes,
  and similarity queries used by this project.
- [Cloudflare Vectorize limits](https://developers.cloudflare.com/vectorize/platform/limits/)
  Official limits for vector dimensions, metadata, namespaces, and query result
  counts.
- [Cloudflare Qwen3 Embedding model](https://developers.cloudflare.com/workers-ai/models/qwen3-embedding-0.6b/)
  Official input schema for query and document embeddings.
- [MCP Inspector](https://github.com/modelcontextprotocol/inspector)
  Official MCP Inspector project. Use for: connect to and test the `/mcp` Streamable HTTP endpoint.

## Wisdom (Communities)
